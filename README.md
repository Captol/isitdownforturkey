# Is It Down For Türkiye?

Free, public reachability checks from inside Türkiye. Bilingual TR/EN. $0 cost.

## Quick Start

```bash
npm install
npm run dev
```

## Architecture

See [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) and [docs/PLAN.md](./docs/PLAN.md).

## Probe Agent

Volunteer probes run from Turkish ISPs. See [docs/PROBES.md](./docs/PROBES.md) for the volunteer guide and [packages/probe/README.md](./packages/probe/README.md) for implementation details.
